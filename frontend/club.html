Students should normally see the WhatsApp link after registering. The button above is only for quick testing.

Admin setup checklist
  1. Open frontend/data/clubs.json.
  2. For this club, set:
    • registration_url -> your Google Form link or Apps Script link.
    • whatsapp_invite_url -> the WhatsApp "Invite via link" URL.
  3. Optional safer flow: use the included Google Apps Script (in google-apps-script/) to record registration to a Sheet and then redirect to the correct WhatsApp link.
Tip: If you prefer to hide raw WhatsApp invite links, use the Apps Script redirect method.
