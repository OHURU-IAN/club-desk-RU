Admin guide

Manage club links and flows

Use this checklist to keep registration and WhatsApp invite links current. Pages are static; all data lives in one JSON file.

< Back to clubs

Quick checklist

  1. Edit frontend/data/clubs.json.
  2. For each club, set:
    • registration_url -> your Google Form link or Apps Script link.
    • whatsapp_invite_url -> the WhatsApp "Invite via link" URL.
  3. Test flow: open index.html -> pick a club -> click Register -> ensure your form redirects to thanks.html?club=<id>.
  4. On thanks.html, verify the WhatsApp button opens the right invite.

Tips

  • Hide raw WhatsApp links from students by using the provided Apps Script redirect method (see google-apps-script/).
  • Keep the id stable; it is used in URLs (club.html?club=id and thanks.html?club=id).
  • Host as a static site (Riara site, GitHub Pages, Netlify, etc.). No server needed.
